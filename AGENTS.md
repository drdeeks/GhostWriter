# AGENTS.md — Ghost Writer

## Essential Setup
```bash
# First install (critical for peer deps)
npm install --legacy-peer-deps

# Configure environment
cp env.example .env
# Edit .env with required keys:
#   PRIVATE_KEY, NEXT_PUBLIC_CHAIN_ID, NEXT_PUBLIC_ONCHAINKIT_PROJECT_ID, NEXT_PUBLIC_ONCHAINKIT_API_KEY
#   STORY_TEMPLATE_SIGNER_PRIVATE_KEY (for user story creation)

# Deploy contracts
npm run deploy:base              # Mainnet
npm run deploy:baseSepolia       # Testnet

# Register story template signer (required after deployment)
npx hardhat run scripts/set-signer.js --network base

# Start development
npm run dev
```

## Key Commands
- `npm run test` - Contract tests (Hardhat)
- `npm run test:frontend` - Frontend tests (Jest)
- `npm run test:all` - Both test suites
- `npm run test:ci` - CI workflow (ts-check + coverage)
- `npm run compile` - Solidity compile
- `npm run verify` - Verify contracts on Basescan
- `npm run lint` - ESLint
- `npm run ts-check` - TypeScript validation
- `npm run build` - Production build

## Critical Quirks
- **Babel presets** (`@babel/*`, `@babel/core`) must be in `dependencies`, not `devDependencies`, or Vercel builds fail
- `@farcaster/miniapp-sdk` must be `^0.2.3` for peer deps
- Solidity: `0.8.28` with `evmVersion: "cancun"` (required for OpenZeppelin v5 `mcopy`)
- `contracts/LiquidityPool.sol` event is `Deposited` (not `Deposit`)
- **Keystore auto-generation**: If `STORY_TEMPLATE_SIGNER_PRIVATE_KEY` unset, deploy creates wallet & prints key/password
- **NFTs mint on-demand**: Not pre-generated; created via `mintHiddenNFT` (contributions) or `mintCreatorNFT` (story completion)
- **Dark mode**: Requires `<html className="dark">` in `src/app/layout.tsx` for Tailwind `dark:` variants
- **Post-deploy**: Always run `npx hardhat run scripts/set-signer.js --network <network>` to register signer

## Architecture Notes
- **Frontend**: App Router codebase — **intended** to run on Next.js 16 + Turbopack, but `package.json` is currently regressed to `next@^9.3.3` (installed 9.5.5). See "Known Issues" below before assuming `next/*` APIs work.
- **Contracts**: Hardhat 2 + ethers v6
- **Wallet**: wagmi/viem + @coinbase/onchainkit
- **Farcaster**: @farcaster/miniapp-sdk + @farcaster/miniapp-wagmi-connector
- **Networks**: Base (8453) or Base Sepolia (84532) via `NEXT_PUBLIC_CHAIN_ID`
- **Entry points**: 
  - Contracts: `contracts/` (StoryManager.sol core)
  - Frontend: `src/app/` (App Router), `src/components/`, `src/hooks/`, `src/lib/`
  - Scripts: `scripts/` (deploy.js, set-signer.js, verify.js)

## Testing Specifics
- Frontend tests: `src/**/*.test.{ts,tsx}` with Jest + jsdom
- Jest config: `@/` paths via `moduleNameMapper`; ignores `@farcaster`, `@coinbase`, `wagmi`, `viem`
- Contract tests: `test/` directory (currently sparse)
- Gas reporting: `REPORT_GAS=true npm test` or `npm run test:gas`

## Deployment Flow
1. Deploys: LiquidityPool, PriceOracle, GhostWriterNFT, StoryManager (+ GhostWriterToken with `--with-token`)
2. Updates `.env` with contract addresses
3. Creates `deployment.json`
4. **Required**: Run `scripts/set-signer.js` to register EIP-712 story template signer
5. NFT metadata dynamically generated by `/api/nft/[tokenId]/route.ts`

## Known Issues
- **`next` regressed to `^9.3.3`** (installed 9.5.5, from 2020 — predates the App Router by 4 years, ships no `next/server` module). Confirmed via git history that this is a regression, not an intentional pin: `next` was correctly `^16.1.4` as of commit `3a10141` (2026-01-24), then silently dragged back down by commit `86f16ec` ("Pre-build state with approved scripts and security fixes", 2026-06-03) — a large grab-bag commit consistent with a bad merge of a stale snapshot. This is the root cause of ~226 `tsc --noEmit` errors across 40 files (`Cannot find module 'next/server'`) and most of the remaining critical/high `npm audit` CVEs (loader-utils, tar, webpack, terser, postcss, chokidar — all bundled inside old Next's tooling). Fix: restore `next` to `^16.x`, then verify the App Router code and `next build --no-turbo` script still line up, before touching anything else dependency-related.
- **32/45 jest suites fail** with `SyntaxError: Cannot use import statement outside a module`. Confirmed pre-existing (reproduces identically on prior commits). Likely cause: two coexisting Babel configs — root `babel.config.js` vs. `jest.config.js`'s inline `next/babel`-based transform override. Not yet root-caused.
- **`hardhat` peer conflict**: `hardhat@^2.22.6` vs `@nomicfoundation/hardhat-network-helpers@^3.0.9` (peer-requires `hardhat@^3.4.0`) — use `npm install --legacy-peer-deps`. No upstream audit fix available yet for hardhat's current advisory.
- **99 known `npm audit` vulnerabilities remain** (22 low, 54 moderate, 24 high, 5 critical) after the safe/non-breaking fix pass — the bulk are blocked on the `next` regression above.
