# AGENTS.md — Ghost Writer

## Essential Setup
```bash
# First install (critical for peer deps)
npm install --legacy-peer-deps

# Configure environment
cp env.example .env
# Edit .env with required keys:
#   PRIVATE_KEY, NEXT_PUBLIC_CHAIN_ID, NEXT_PUBLIC_ONCHAINKIT_PROJECT_ID, NEXT_PUBLIC_ONCHAINKIT_API_KEY
#   STORY_TEMPLATE_SIGNER_PRIVATE_KEY (for user story creation)

# Deploy contracts
npm run deploy:base              # Mainnet
npm run deploy:baseSepolia       # Testnet

# Register story template signer (required after deployment)
npx hardhat run scripts/set-signer.js --network base

# Start development
npm run dev
```

- `npm run test:contracts` - Contract tests only (Hardhat)
- `npm run test:frontend` - Frontend tests (Jest)
- `npm run test:all` - Both test suites

## Critical Quirks
- **Babel presets** (`@babel/*`, `@babel/core`) must be in `dependencies`, not `devDependencies`, or Vercel builds fail
- `@farcaster/miniapp-sdk` must be `^0.2.3` for peer deps
- Solidity: `0.8.28` with `evmVersion: "cancun"` (required for OpenZeppelin v5 `mcopy`)
- `contracts/LiquidityPool.sol` event is `Deposited` (not `Deposit`)
- **Keystore auto-generation**: If `STORY_TEMPLATE_SIGNER_PRIVATE_KEY` unset, deploy creates wallet & prints key/password
- **NFTs mint on-demand**: Not pre-generated; created via `mintHiddenNFT` (contributions) or `mintCreatorNFT` (story completion)
- **Dark mode**: Requires `<html className="dark">` in `src/app/layout.tsx` for Tailwind `dark:` variants
- **Post-deploy**: Always run `npx hardhat run scripts/set-signer.js --network <network>` to register signer

## Architecture Notes
- **Frontend**: Next.js 16 (App Router), built with webpack (`next build --webpack` / `next dev --webpack` — Turbopack is disabled, see "Known Issues")
- **Contracts**: Hardhat 2 + ethers v6
- **Wallet**: wagmi/viem + @coinbase/onchainkit
- **Farcaster**: @farcaster/miniapp-sdk + @farcaster/miniapp-wagmi-connector
- **Networks**: Base (8453) or Base Sepolia (84532) via `NEXT_PUBLIC_CHAIN_ID`
- **Entry points**: 
  - Contracts: `contracts/` (StoryManager.sol core)
  - Frontend: `src/app/` (App Router), `src/components/`, `src/hooks/`, `src/lib/`
  - Scripts: `scripts/` (deploy.js, set-signer.js, verify.js)

## Testing Specifics
- Frontend tests: `src/**/*.test.{ts,tsx}` with Jest + jsdom
- Jest config: `@/` paths via `moduleNameMapper`; `wagmi`, `@wagmi/core`, `viem`, `viem/chains`, `@coinbase/onchainkit` are all replaced with hand-written mocks in `src/test-utils/mocks/` (not real modules — extend those mocks with realistic default return shapes when adding hooks, not bare `jest.fn()`, or destructuring calls will crash)
- `src/test-utils/setup-tests.ts` imports `polyfills.ts`, which bridges Node's native `undici` (fetch/Request/Response/Headers) and `node:stream/web` into the jsdom global — required for anything touching `next/server`'s `NextRequest`/`NextResponse`
- Contract tests: `test-contracts/` directory (`hardhat.config.js`'s `paths.tests`)
- Gas reporting: `REPORT_GAS=true npm test` or `npm run test:gas`

## Deployment Flow
1. Deploys: LiquidityPool, PriceOracle, GhostWriterNFT, StoryManager (+ GhostWriterToken with `--with-token`)
2. Updates `.env` with contract addresses
3. Creates `deployment.json`
4. **Required**: Run `scripts/set-signer.js` to register EIP-712 story template signer
5. NFT metadata dynamically generated by `/api/nft/[tokenId]/route.ts`

## Known Issues

### Fixed (2026-08-04) — history kept for context
A merge commit (`86f16ec`, "Pre-build state with approved scripts and security fixes", 2026-06-03) silently regressed a cluster of dependencies that had been correct as of commit `3a10141` (2026-01-24) — most critically `next` from `^16.1.4` down to `^9.3.3` (predates the App Router by 4 years, ships no `next/server` module at all), while dropping `@farcaster/miniapp-sdk`/`@farcaster/miniapp-wagmi-connector` from `package.json` entirely despite 7 files importing them, and mismatching `@nomicfoundation/hardhat-network-helpers` (bumped to `^3.0.9`, built for hardhat v3's plugin system) against `hardhat-toolbox` (downgraded to `^3.0.0`), silently breaking `loadFixture` for every contract test. All restored — `npm run build`, `npm run test:contracts`, and `tsc --noEmit` are all verified clean. See CHANGELOG.md's 2026-08-04 entry for the full fix list (Next/React/Tailwind/wagmi/onchainkit version coherence, babel config fixes, jest transform fixes).

### Still open
- **Turbopack is disabled** (`--webpack` flag on both `dev`/`build`) — the codebase was never verified against Turbopack; re-enabling it would need its own pass.
- **~39 jest test failures remain**, confirmed as pre-existing application/test-content mismatches, not infrastructure issues (test infra itself is now solid — 278/317 passing). Example: a route test asserts an error message the route no longer returns, meaning the API contract changed since the test was last updated. Needs per-test triage to decide whether the test or the implementation is stale.
- **71 `npm audit` vulnerabilities remain** (19 low, 45 moderate, 7 high, 0 critical — down from 113 at session start; critical hit zero once the dependency versions were made coherent). Not yet triaged individually.
- Socket.dev CLI is set up (`socket login`, org `drdeeks-unique-antiques`) for supply-chain scanning going forward; the org's default security policy currently `ignore`s nearly everything, so it isn't gating anything yet.
